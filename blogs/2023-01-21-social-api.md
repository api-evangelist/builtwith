We recently launched a new Social API endpoint! This endpoint lets you search for web domains related to a social media profile, so for example you could send the API "samsclub" and it would tell you all of the social network links we've found that mention this like facebook.com/samsclub and then all of the sites that we found that link on like samsclub.com. The lists of domains also provides a 'rank' so you can tell which sites are legitimate and which ones are randomly linking to the social network page.
