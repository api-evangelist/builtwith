We've launched the BuiltWith VAT API , a new API for finding VAT numbers and other company registration identifiers from website domains. Give the API a domain and it can return available VAT, ABN, ACN, CNPJ, GSTIN, EIN, SIREN, SIRET and other company registration numbers that BuiltWith has identified from publicly available information on websites. The API is designed for workflows where you already have a website or business email domain and want to enrich that information with company registration data.
