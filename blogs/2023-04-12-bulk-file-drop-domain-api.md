We just created a new super easy to use bulk file drop Domain API endpoint at https://api.builtwith.com/bulk-file-domain-api . Instead of having to use the more complex SFTP endpoint you can now simply drag and drop your domain list into this tool and it will provide a ZIP download of all the technologies currently and historically in use on your upload list. You can view a sample ZIP file here that shows the detailed output format for this tool.
